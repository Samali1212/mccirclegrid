3D Sphere & Dome Construction Guide

Building a voxel sphere requires stacking horizontal circular slices. Each slice is a 2D circle whose radius depends on its vertical offset from the equator.

Sphere Radius Mathematics

For a sphere of radius R, the radius of the horizontal slice at vertical offset Y is:

r(Y) = √(R² - Y²)

Use this formula to determine the diameter of each layer when building manually.

Layer-by-Layer Construction

  1. Select sphere mode in the generator.
  2. Set the diameter (equal to 2R).
  3. Navigate layers using the layer slider.
  4. Enable Ghost Layer (Y−1) to see the layer below for scaffolding reference.
  5. Build each layer from bottom to top, following the displayed perimeter.

Overhang & Scaffolding

When a block on the current layer extends beyond the ghost layer below, it forms an overhang. Place temporary scaffolding underneath to build outward without falling.

Survival Construction Workflow

  • Start from the bottom layer (Y=0) and work upward.
  • Always place scaffolding for overhanging blocks.
  • Use the ghost layer to verify where you can safely stand.

Useful Commands

WorldEdit commands for quick sphere creation:

  • //sphere <block> <radius> — solid sphere
  • //hsphere <block> <radius> — hollow shell
  • //hcyl <block> <radius> <height> — hollow cylinder (for domes)
